# MM YouTube Downloader

One-command YouTube video/MP3 downloader for Windows. No Python needed.

**Install:** visit the site and click Download Setup, or run in PowerShell:
```
irm https://mahendra0905.github.io/mm-youtube-downloader/go | iex
```

**Use (new terminal):**
```
mm "https://www.youtube.com/watch?v=XXXX"   # video mp4
mk "https://www.youtube.com/watch?v=XXXX"   # audio mp3
```

Powered by yt-dlp + ffmpeg (open source). Made by Mahendra.
