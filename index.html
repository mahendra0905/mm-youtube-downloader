MM YouTube Downloader

Download any YouTube video or MP3 with one short command. Share it, install it, done — no Python, no fuss.

⬇ Download Setup

Double-click the downloaded file. It fetches everything, then asks Y/N to install.

— or, paste this in PowerShell —

irm https://mahendra0905.github.io/mm-youtube-downloader/go | iex
1
Download & run — double-click MM-Setup.bat. If Windows warns, click More info → Run anyway.
2
Wait for download — it grabs the engine (and ffmpeg/node only if your PC lacks them).
3
Press Y to install — when it asks, type Y and Enter. It adds itself to PATH.
4
Open a NEW terminal — then just type the command below.

How to use

VIDEOmm "https://www.youtube.com/watch?v=XXXX"
MP3mk "https://www.youtube.com/watch?v=XXXX"

Files save to your Downloads folder. Some private/age-restricted videos need you signed in to YouTube in Firefox/Chrome/Edge — the tool borrows that login automatically.

Made by Mahendra · powered by yt-dlp + ffmpeg (open source)
